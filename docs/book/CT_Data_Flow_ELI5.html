CT 한 쌍은 어디로 갈까?

저선량은 연습 문제, 정상선량은 비교할 답안. 버튼을 눌러 한 쌍의 여행을 따라가세요.

새 노트북은 7개 장입니다.
3장 Dataset → 1장 파일 읽기·3장 정규화 → 다시 3장 Tensor·배치 → 5장 모델·학습.
아래는 함수 호출 시 데이터가 이동하는 순서입니다. 각 원문 카드의 새 장·작업 이름으로 코드를 찾으세요.

전체 지도
경로→HU 배열→정규화→같은 위치 자르기→Tensor→배치→모델 출력→차이 계산→가중치 수정
학습의 핵심: 저선량만 모델에 넣고, 출력과 정상선량을 비교해 모델을 수정합니다.
그림 속 숫자와 작은 격자는 이해를 위한 예시입니다. 실제 CT 그림이나 측정 결과가 아닙니다. 정상선량은 비교 기준이며 완벽한 정답을 뜻하지 않습니다.
교재 3장: 모델 입력 · 교재 5장: 학습
