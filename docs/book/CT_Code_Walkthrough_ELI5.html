6장 · 마지막 테스트에는 별도 함수가 없어요
실행 셀에서 load_trained_model → load_split_rows("test") → 학습·검증 환자와 겹치지 않는지 확인 → 단면마다 read_normalized_pair → predict_ct_image → calculate_metrics → summarize_test_rows → CSV·JSON 저장 순서로 진행합니다. 테스트에서 가중치를 갱신하지 않습니다.
